# 🏴‍☠️ Lost Pirate
Lost Pirate é um protótipo de jogo de aventura em plataforma desenvolvido na Unreal Engine 5.0, utilizando diversos recursos avançados como o ALS (Advanced Locomotion System) e Quixel MegaScans.

Neste jogo, você controla um pirata solitário que acaba de chegar a uma ilha misteriosa em busca de um tesouro perdido. Prepare-se para explorar um ambiente perigoso, enfrentar inimigos e desvendar pequenos puzzles!

## 📦 Funcionalidades Principais
### 🎮 Jogabilidade
- Movimentação avançada com ALS: correr, escalar, pular, mirar e atirar.
- Combate: sistema de mira e disparo contra inimigos.
- Sistema de pickups: itens que recuperam a vida do jogador.
- Checkpoints: salvamento de progresso em pontos-chave do mapa.

### 🌴 Ambiente e Mundo
- Landscape realista com um vulcão ativo, rios e vegetação densa.
- Sistema de oceano com barcos flutuantes e física interativa.
- Barreiras invisíveis para limitar o acesso a áreas fora do gameplay.
- Cutscenes simples de introdução (entrada na caverna) e finalização do jogo.

### 🧩 Puzzles e Plataformas
- Puzzle simples de alavanca que abre paredes secretas.
- Plataformas móveis sobre áreas com espinhos mortais.


## 📥 Como Baixar e Executar
⚠️ Este projeto utiliza o Git LFS (Large File Storage). Certifique-se de tê-lo instalado antes de clonar o repositório.

```git lfs install
git clone https://github.com/crazymaax404/TheLostPirate.git
```
Abra o projeto com a versão **5.0** da Unreal Engine.
